# 预算固定概览与剩余池百分比

更新日期：2026-11-04。移动端 0.1.8 / versionCode 9。

## 交互

- 删除明细编辑页额度旁打开扩展配置的滑杆按钮，保留类别额度编辑。
- 预算分配的总额度、当前可分配金额与剩余池分配情况固定在弹窗顶部，不随类别滚动。Android 软件键盘弹出时仍保留在可见区域。
- 输入框按模式分别显示“固定金额（元）”“总额百分比（0–100）”“剩余池百分比（0–100）”，不再将金额、百分比和权重混为一个说明。

## 计算和保存

假设总额度为 10000 元，日用品固定金额 200 元，交通按总额 10%：

1. 日用品为 200 元，交通为 1000 元。
2. 剩余池为 `10000 − 200 − 1000 = 8800` 元。
3. 某类别输入剩余池的 25%，得到 `8800 × 25% = 2200` 元。其余 75% 继续保留，其他剩余池类别可分配。

各剩余池类别均按同一个剩余池计算，不按输入顺序递减基数，也不将 25 自动理解为权重而领取全部剩余。各项比例可为 0，最多两位小数；剩余池比例合计不能超过 100%。金额以整数分计算，多类别舍入按小数余数稳定分配，不重复领取尾差。

固定金额与总额百分比的合计允许超过计划总额度。超过时页面显示超出金额和“不可完成剩余分配”，所有剩余池类别均须设置 0% 或改用其他分配模式，才能保存该超额计划。不会将超出金额转换为负储蓄或自动提高总额度。

新增接口字段 `remainderBps` 和数据库字段 `budget_items.remainder_bps`，百分比 25 对应 2500 基点。迁移 016 将旧版剩余权重转换为合计 100% 的比例；服务端仍兼容旧版仅提交权重的请求。前端、API 和数据库同时检查剩余分配边界。既有按 ID 关联、删除过滤及月份隔离保持有效。
