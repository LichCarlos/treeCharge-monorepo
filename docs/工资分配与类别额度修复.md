# 工资分配与类别额度修复

更新日期：2026-11-04。移动端 0.1.7 / versionCode 8。

## 分配流程

选择工资模板创建账本后直接进入预算分配。先填写可支配总额，再填写各类别固定金额、百分比或剩余分配权重。模板只预备类别，不生成工资收入或示例支出。

总额度 10000 元、日用品 200 元时，交通输入框显示“当前可分配 ¥9,800.00”。输入和修改金额时实时重新计算；编辑已有类别时，其原额度计入可调整空间。剩余分配项自动取得未被固定金额及百分比占用的部分。百分比始终按总额度计算。

整份分配必须填写所有必填值，可以明确填写 0。分配超过总额度时不提交。草稿也可从单类别入口逐条设置，总额和所有有效类别完成后自动生效。在对应月份仍有工资分配草稿时，新建收支由客户端和服务端共同拦截，记账页提供“完成工资分配”入口。

## 实际类别关联

预算编辑从数据库中当前账本的有效类别及其 ID 生成，不重新使用模板快照。删除类别后，其旧分配不出现在编辑列表；修改名称同步显示；新建同名类别具有独立 ID，不继承旧类别记录或额度。工资账本中新加的支出类别会进入预算设置。

保存重新检查有效类别集合、账本归属及预算版本。编辑期间类别发生变化时，提示重新读取额度，避免提交失效关联。退役预算项及删除映射保留历史，下一次成功保存分配时将其额度归零，释放预算空间，不物理删除软删除数据。

## 单类别修改

记一笔和明细编辑中的上限入口只展示选中类别，不展开其他类别字段。已生效工资预算不展示总额输入；草稿可补填总额。类别管理中的工资额度也复用同一个编辑器。

修改一个类别时，其余固定金额和百分比规则不变；剩余分配项自动重算，不新增或更改真实收支。共享旧预算桶中的类别按 ID 分离，保留其余类别原有共同额度，新增单独额度仍受总额限制。普通账本继续支持独立上限以及留空取消上限。

所有额度按工作区、账本、月份共享缓存，保留历史月份隔离。预算表单每次打开先读取服务端最新状态，也提供重新读取入口。
