# 复杂表单逐项填写优化

## 范围

工资与类别额度、账本创建、存款计划创建/编辑、标签与字段设置等多字段业务表单，共用 `FormSteps`。类别编辑原有的长页面也接入同一组件，保留图标绑定、账本多选、收入类别无需额度等规则。

记一笔计算器、四列三排类别、备注交互保持原有逻辑；其附加信息弹窗显式沿用普通表单。登录注册、单字段修改和删除确认仍采用原交互。

## 操作规则

1. 上方显示当前字段名称、必填状态和填写进度，下方显示本项输入或选择控件。
2. 点击上一项/下一项切换。字段标题区域支持左右滑动，与输入框光标、图标库横向分页分开，避免误操作。
3. 文本字段自动聚焦；日期、多选、图标等字段保留对应专用控件。必填未完成时留在当前项。
4. 最后一项进入总览，不立即写入业务数据。总览显示选项名称而非内部 ID，密码只显示“已填写”。
5. 点击总览某一项可单独修改，随后直接返回总览；确认保存才调用原业务接口。
6. 仍沿用用户隔离的草稿和操作 ID；敏感字段不写草稿。保存失败保留输入，可修正或重试；提交期间防止重复点击。

## 键盘与布局

将共享弹窗的键盘避让移到外层视口，避免键盘高度直接从内容面板扣除。键盘显示时使用紧凑字段标题，隐藏重复预算摘要，单项提示在输入前显示。输入区域在可用空间变化时保持输入框可见，前后切换按钮在内容滚动区之外。

工资分配计算、预算归属、流水生成和服务器接口未改动。实际类别仍来自对应账本当前数据。
