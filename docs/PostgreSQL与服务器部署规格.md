## 2. 运行架构

```text
Expo Android APK
  ├─ 界面状态、可恢复草稿、有限读取缓存
  └─ HTTPS /v1（访问令牌、操作ID、预期修订号）
          ↓
       Nginx（独立项目域名/路径，保留既有站点）
          ↓
       Node.js 22 + TypeScript + Fastify API（独立systemd进程，回环地址端口）
          ↓
       pg连接池（参数化SQL、服务层校验、事务、有限重试）
          ↓
       PostgreSQL：charge数据库 / charge schema
```

手机不内置PG密码、SSH密钥或管理员令牌。数据库运行密码仅留服务端受限配置文件，不进入EXPO_PUBLIC变量、源码、备份示例、日志或APK。API账号不同于SSH/PG账号。

正式API的域名与证书接入尚未设置，不能把公网IP上的HTTP当作正式手机接口。开发可用SSH隧道访问服务；数据库工具也仅用SSH转发回环5432。普通手机使用依赖服务器可达，不依赖用户电脑或Termius持续打开。

## 3. 在线与离线边界

- 正式写入、预算余额、查询统计、模板实例化以服务端提交结果为准。
- 离线可编辑本机草稿、查看已有缓存；显示缓存时间和状态，不承诺完整离线统计。
- 一期不做离线自动入账队列或双向同步。网络失败不显示成功，不在手机扣其他tag的最终余额。
- 超时结果未知时按operationId查服务端，再决定重试；同一ID不同请求返回冲突。
- 编辑携带expectedRevision，服务端事务内不匹配返回409及最新修订；用户处理差异，不静默覆盖。
- 手机卸载不删除服务器数据；会丢失未提交草稿和本机缓存。重新认证后读取服务器记录。

## 4. 数据结构与已实现约束

主数据表覆盖工作区、实体、树、分组、两类账本、主分类、明细、备注、存钱目标、来源、计划、辅助标签、自定义字段与选项、附加关系、模板版本与实例、预算方案/项/桶/映射/修订/使用、扣额/撤销、退款引用、审计、删除批次、设置、导出任务。身份基础包括app_users（system_role等）、workspace_members、auth_sessions、api_operations及system_audit_events。

- UUID保证稳定引用；workspace_id复合外键防跨工作区错误绑定。
- 金额整数分，money_minor为非负bigint域，实际账目必须大于0；余额由视图派生，可为负。JSON传输中的金额按受控安全整数校验，PG bigint由API显式转换。
- 日期使用date，审计使用timestamptz；业务“今天”取工作区时区。
- 根唯一、父子类型、防循环、分类所属账本、明细/备注父节点在约束触发器内验证。复杂移动在事务中更新后校验最终树。
- 唯一备注、方向限制、字段值类型、单选唯一、关系基数、初始预算上限、实际存钱非负、退款额度、来源分配有数据库校验。
- 父节点软删除后，visible_tree_nodes递归排除其全部后代，预算使用随之退出计算；恢复后重新可见。
- budget_category_mappings显式映射每个分类到同一预算期的唯一互斥桶。父项汇总不重复扣额，未映射消费不伪造预算。
- 实际消费增改会自动维护预算使用投影，预算生效及分类映射变化可重建已有消费。
- 函数compensate_negative验证负目标、正来源、缺口、同方案、多来源与幂等，在一个事务里写双边事件。
- 函数reverse_budget_transfer追加反向事件，拒绝重复撤销；实际transactions不被改写。
- 已提交扣额、修订和审计不可覆盖；运行账号不能直接插入扣额事件或改系统模板。

当前数据层是一期基础，不能视为全部业务已经完成。作用域后代判断、字段必填迁移、关系定义收紧、分类同级名称策略、预算规则计算与修订交互、储蓄/退款预算占用联动、删除影响预览、个人模板写入接口、账号管理和可恢复导出任务仍由后续API用例完成并补充数据库约束与集成测试。尤其不能直接开放通用SQL/任意表CRUD作为正式API。

工作区写入用行锁串行协调关键业务，避免同一余额被并发消费；不同工作区可以并行。正式API所有金额相关用例均先锁工作区，再查修订和余额；禁止绕过服务随意修改投影。当前深树校验以正确性为先，发布前须针对既定50,000条数据优化验证范围并实测，不能据基础测试宣称性能达标。

## 5. API与身份约定（待实施）

支持用户名/密码公开注册，注册固定创建普通用户与空工作区；系统超级管理员由服务端初始化，具有跨用户全部业务数据增删改查权限。密码采用scrypt带盐散列；短期访问令牌、可撤销刷新会话，刷新令牌仅存摘要。手机凭据存SecureStore。登录限速；日志不记录密码、令牌或完整备注。

每次请求核验用户状态、auth_version、system_role及workspace_members，再定位资源；超级管理员可跨全部用户工作区管理数据，普通用户限定授权范围。客户端给出workspaceId不代表授权；权限校验覆盖列表、详情、导出、下载、预算函数调用。当前PG账号由同一API进程使用，授权必须逐路由落地，尚不构成已实现的多用户隔离API。

| 路由组 | 规划用途 |
| --- | --- |
| POST /v1/auth/register、login、refresh、logout | 注册普通用户、登录、续期与会话撤销 |
| /v1/admin/users、workspaces、templates、settings、audit-events | 超级管理员跨用户全量管理，逐业务用例授权与审计 |
| GET /v1/workspaces | 普通用户自己的工作区；管理员可选择全部工作区 |
| /v1/workspaces/:id/tree、ledgers、categories | 树、账本、分类及影响预览和移动 |
| /v1/workspaces/:id/transactions、plans、savings-goals | 记账、退款、计划确认和存钱 |
| /v1/workspaces/:id/tags、fields、relations | 配置、值、绑定、反查及迁移 |
| /v1/templates、/v1/workspaces/:id/template-instances | 模板配置和幂等创建 |
| /v1/workspaces/:id/budgets | 规则、修订、互斥桶、执行视图 |
| POST .../budgets/:planId/compensations | 预期修订、负目标与多来源扣额 |
| POST .../budget-transfers/:id/reversals | 预览后追加反向事件 |
| /v1/workspaces/:id/queries、charts | 相同筛选口径的列表/统计/下钻 |
| /v1/workspaces/:id/operations/:operationId | 查询未知结果，避免盲目重复提交 |
| /v1/workspaces/:id/exports、trash | 认证后的导出任务、下载、回收站 |

关键写接口统一operationId和请求摘要，状态码包括400/401/403/404/409/422/503。分页采用稳定游标；拒绝无界列表、SQL片段、任意排序字段；缓存按工作区与修订失效。角色授权通过后，API在事务里完成业务记录、预算投影、审计与幂等响应。

## 6. Excel、备份与恢复

XLSX改由服务端基于PG一致性快照生成，手机只发起、下载、分享/另存。复用领域金额口径和已有工作簿排版，原手机端XLSX库技术验证改为服务端内存、队列和下载验证。只导出授权范围，下载不可用猜测路径绕过鉴权。临时文件生命周期与取消清理在API阶段实现。

数据库运维备份使用pg_dump -Fc，包含全部工作区与身份数据，只供管理员操作；不能通过普通手机“导出”接口直接下载全库dump。用户业务数据备份应由授权API生成带schema版本及校验摘要的单工作区包，恢复在隔离暂存区校验、预览后事务提交。

已提供server/ops/backup-db.sh，文件存/var/backups/charge，附SHA-256。PG密码和SSH密钥不写入数据备份。备份内含用户数据和密码散列，应以管理员权限保存。计划每日备份、保留7个每日和4个每周版本、加密异机副本；定时任务、异机目标和密钥保管尚待配置，不把单机备份称为灾备完成。

恢复先建明确命名的隔离数据库，pg_restore校验外键、树、模板、扣额和金额，再切换应用配置；原库保留到验证完成。上线迁移先备份，旧迁移按校验和不可修改，失败整个迁移回滚。APK升级与API版本、DB迁移解耦，保留兼容窗口，禁止客户端触发清库或全库恢复。

## 7. 复现与交付边界

部署脚本：server/ops/deploy-db.sh。仅操作charge专用库/账号/schema，不重配现有PG服务；重复执行核验迁移哈希和模板版本，不重置密码。SQL修复通过追加迁移。

数据库测试：server/db/tests/integration.sql。管理员会话创建临时测试辅助函数后切换charge_app执行断言，创建测试工作区，全部回滚；金额守恒、幂等、多来源、撤销、失败回滚及运行账号禁止覆盖历史均有验证。正式API阶段追加跨用户访问、并发、断网重试与性能测试。

阶段完成证据与恢复演练见[服务器数据库实施记录](服务器数据库实施记录.md)。本次数据库落实不等于已上线可供手机使用的服务。
