# 记账备注与键盘交互

更新：2026-11-03，移动端 0.1.2。

## 输入行为

- 点备注，系统文字键盘弹出，金额计算键盘收起。备注与金额栏保持在文字键盘上方。
- 备注为多行输入，文字输入时增长至限定高度后在框内滚动，最多 5000 字；返回金额键盘时缩回紧凑高度，点击备注可继续查看与编辑完整内容。
- 点击「完成备注」、金额或系统收起键盘按钮，返回原金额计算键盘，金额、日期、类别和备注保留。
- 记账页使用原生安全区域，标题避开状态栏；类别仍为两行，超出左右翻页。
- Android 全屏弹窗显式按键盘高度避让，避免系统键盘覆盖备注。小屏输入时临时收起顶部导航、收支切换和类别标题，保留两行类别、常用备注、金额和备注栏；收起键盘后恢复完整页面。
- 保持现有全局主题色、类别选择、预算余额提示和草稿保存逻辑。
- 小屏减少顶部与计算器间距；类别图标按实际行高缩放，避免备注增加后挤压两行类别并造成按钮重叠。

## 常用备注

- 备注栏上方以横向滑动按钮展示当前类别的常用备注，点击一次将完整备注填入，之后可继续编辑。
- 数据来源是用户已经保存的真实记录。未选类别、没有历史备注时不显示示例或虚构备注。
- 按工作区、账本、类别和收支方向隔离，跨月份统计；相同名称但 ID 不同的类别互不混用。
- 相同备注去除首尾空格后合并，使用次数越多越靠前，同次数以最近记账日期排序。最多显示 12 个常用项，与流水展示数量无关。
- 删除的流水、备注以及隐藏在已删除账本/类别下的记录不参与；编辑记录时排除该条记录本身。恢复记录后重新参与统计。
- 请求失败时保留手动输入能力；切换类别时立即隐藏上一类别的推荐，过期请求不会覆盖当前结果。
- 没有增加新的收支流水或业务实体，也没有改变记录与一对一备注的数据结构。

## API

`GET /v1/workspaces/:w/categories/:id/remark-suggestions?direction=expense&excludeId=<可选记录ID>`

返回 `[{remark, uses, last_used}]`。需要有效会话和工作区访问权限；类别与账本必须可见，收支方向需要有效。

后端已在 PostgreSQL 13 的独立临时数据库通过完整集成测试，包括跨月份、频次合并、收支隔离、类别隔离、越权拦截、编辑排除与删除恢复。测试数据不写入实际用户工作区。

## Android 验证

2026-11-03，在 Android 15 / API 35、720×1280 小屏模拟器中验证真实 `RecordComposer` 与系统软键盘：

- 备注输入框底部位于输入法上方，文字输入时金额键盘隐藏，类别两行没有覆盖常用备注。
- 一次点击「午餐」填入后可继续输入长备注，输入框内滚动正常。
- 「完成备注」恢复金额键盘；关闭再打开恢复金额、类别和完整备注草稿。
- 切换到「购物」只显示该类别的常用备注，切回「餐饮」后选择「晚餐」，保存回调收到完整备注及准确的 1234 分金额。
- 原生与 React Native 错误日志无异常，移动端类型检查通过。

测试应用使用独立包名及本机模拟数据，未向用户账号写入记录；测试入口已在正式打包前移除。截图为隔离测试界面：[金额键盘](screenshots/record-remarks-amount.png)、[备注输入](screenshots/record-remarks-keyboard.png)。尚未进行实体手机验收。
