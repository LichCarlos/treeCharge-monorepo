# 记一笔三排类别与备注输入优化

本次按用户提供的第 3、4 张交互参考图调整记一笔页面，沿用现有黄色主题和共享图标库。取代 0.1.13 中两排类别、备注输入时隐藏类别的设计。

## 布局

- 类别固定四列三排，每页 12 个位置，添加类别占其中一个位置；超过一页左右滑动查看。
- 网格下方固定预留 24dp 分页指示带，展示当前页位置。只有一页时仍保留一个指示点。
- 名称保持单行省略，自定义名称、图标绑定和类别 ID 不改变。
- 金额计算器使用受限高度，避免高屏幕把按键拉得过大。页面和类别均无纵向滚动。

## 备注输入

- 类别网格持续挂载，保留所选类别和翻页位置，不再用大文本框替换类别区。
- 系统键盘出现时，仅替换下方金额键盘，输入栏紧贴系统键盘上方。
- 备注输入栏保持紧凑高度，长备注在输入框内部滚动，金额持续可见。
- 常用备注仍可一键填入。小屏空间不足时将常用备注移入顶部操作栏，收起键盘后恢复收支切换。
- 不添加“完成备注”按钮；使用系统键盘完成/收起，或点击现有金额返回数字键盘。
- Android 高度补偿仅在键盘可见时生效，避免收起后留下空白。

## 验证范围

验证使用独立模拟数据和独立 Android 测试应用，不读写用户账目。Web 验证覆盖 320×568、360×640、390×844、412×915、480×1040，检查三排网格、分页、添加类别、紧凑备注、快捷备注、计算器恢复和页面无纵向滚动。

Android 使用 API 35 模拟器验证 360×640、320×568、390×844dp，以及 130% / 200% 字体缩放；截图保存在 `docs/screenshots/record-grid-native-*.png`。模拟器输入法不能代表所有品牌真机输入法。

固定三排与无纵向滚动在极小屏幕中属于密度取舍：小屏金额按键可能小于 48dp；键盘展开后类别格会随可用高度缩小，最紧凑时类别标签不放大，以避免图标和文字重叠。常规页面正文仍跟随系统字号。

类别标签的字号与行高使用相同的受限系统缩放值计算，避免 Android 大字号下行高超过测量值而裁切图标。原生检查同时验证圆形图标的可见宽高相等，防止仅检查文字边界而漏掉圆形裁切。

相关回归包括 205 条流水完整查询、单类别额度保存、收入无额度、五种主题、100 图标共享管理和 Web 恢复入口隐藏；计算器与额度现有单元测试同时验证。
