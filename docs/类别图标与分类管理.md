# 类别图标与分类管理

## 图标绑定

`packages/categories/index.mjs` 统一维护 100 个稳定图标 ID、名称及本地 Ionicons 字形。服务端校验、模板初始化、类别管理、快捷记账、消费明细和存款记录均使用该目录，图标资源随 APK 打包。

每个类别保存一个 `icon_id`，同一图标允许绑定多个类别，不设唯一约束。修改类别名称保留原图标；修改绑定后，各页面根据类别 ID 读取更新后的图标。旧类别通过迁移一次性补齐，新增类别可自行选择。

选择器提供“全部 / 已绑定 / 未绑定”，不区分常用和拓展。绑定状态由当前所选账本中的可见类别计算；多选账本创建时按所选账本合并统计。已绑定的图标可以继续选择，显示绑定的类别数量。删除类别后，绑定统计相应更新。

## 分类管理交互

从记账页的“管理类别”或新增入口进入完整管理页，保留记账草稿。管理页显示账本、类别数量、支出/收入切换、图标与名称、删除和拖动排序；底部固定“自定义分类”。存款账本相应切换为存入/取出。

自定义页面填写名称、选择图标并保存。图标横向分页，每页 20 个，支持点击分页点。展开“账本、用途与消费上限”可批量选择同类型账本、设置双向用途和当月预算。批量创建仍为每个账本创建独立类别记录。编辑类别只修改当前类别，不影响其他同名类别或使用相同图标的类别。

排序按账本存储，保留未显示方向类别的位置；服务端校验完整类别集合和版本，防止跨账本操作及并发覆盖。辅助功能支持上移/下移。删除使用已有回收站规则，可恢复。

## 明细编辑

点击消费明细行或编辑按钮均打开该流水 ID 的编辑页，加载金额、日期、类别和备注。保存时提交该流水版本，不跳转类别详情，不修改同类别下其他流水。

## 数据迁移

`012_category_icons_and_order.sql` 新增图标字段、合法 ID 约束，并初始化旧类别图标与顺序。保留用户金额、备注、账本及类别归属。重复图标绑定合法。

## 验证

- 图标目录数量、真实字形、迁移约束一致性、绑定统计、改名保留绑定及不可变排序通过自动化检查。
- PostgreSQL 13 API 集成测试覆盖图标校验、重复绑定、旧客户端保留图标、排序版本冲突、权限隔离、单笔明细修改与历史图标同步。
- 实际 App 网页交互通过单笔修改、多账本独立创建、图标分页、改名与图标同步、绑定筛选及同图标重复使用验证；使用隔离数据，不向真实账户插入测试记录。
- Android 15 / API 35、720×1280 小屏模拟器使用实际 App 和隔离接口响应，验证单笔修改为 1231 分、拖动排序并保留收入类别位置、支出/收入切换、自定义分类、重复绑定及数量为 2、已绑定/未绑定选中状态、记账页新类别同步，以及备注位于系统输入法上方。独立测试包已卸载，测试入口在正式构建前移除；尚未进行实体手机验收。
