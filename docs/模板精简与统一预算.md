# 模板精简与统一预算

更新日期：2026-11-03。移动端 0.1.5 / versionCode 6。

## 创建入口

- 收支账本默认手动创建，不预选模板；模板库和创建下拉仅显示工资分配。
- 工资模板只创建类别和待设置的月度分配方案。总额、固定金额及百分比由用户填写，不生成示例收入或支出。
- 存款计划只保留自定义目标，必填名称及正数目标金额，日期可选。不再依赖账本模板。
- 服务端模板列表只返回最新工资模板，拒绝新实例使用已移除的模板 ID。历史模板版本保留，避免破坏已有实例的来源引用。

## 额度状态与编辑

`budgetStore` 按工作区、账本、月份保存共享快照，相同范围的读取合并为一个请求。记一笔和明细中的记录编辑使用同一个 `RecordComposer`；类别管理、记录页和预算页的额度统一使用 `categoryAllowanceIndex` 与 `CategoryAllowanceBar`。

每次成功写入工作区数据都会使该工作区所有额度快照失效，并刷新主页面。跨月退款、流水修改、删除或调剂后也重新读取。请求代次校验阻止写入前启动的旧请求覆盖新额度；切换账号时清空缓存。

- 普通类别可在记录页点击额度设置，也可在类别编辑中直接填写消费上限，无需展开高级设置。空值代表不设置上限，零代表上限为零。
- 工资分配尚未生效时，点击待设置额度打开完整分配表单；共享预算桶也打开完整方案，避免把同一桶错误拆成独立额度。
- 工资总额与分配守恒由服务端校验。保存使用类别及预算版本号，避免旧表单覆盖已修改的数据。
- 从记录进入类别管理，使用该记录日期所属月份；独立打开类别管理时默认当月。类别本身仍是字典项，不增加日期筛选界面。
- 额度不等同于真实流水。修改上限和分配不会新增、修改已有收支金额。

## 验证

- 共享状态测试覆盖请求合并、工作区隔离、失效刷新、旧响应防覆盖及失败重试。
- PostgreSQL 13 独立测试库覆盖模板筛选、移除模板拒绝创建、工资草稿生效、既有支出计入余额，以及修改类别额度保持工资总额守恒。
- 实际 Expo Web 页面验证新建记录、编辑明细、类别管理互相同步，历史月额度与当前月隔离，以及工资草稿激活和创建入口选项。
