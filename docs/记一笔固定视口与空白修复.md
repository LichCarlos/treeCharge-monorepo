# 记一笔固定视口与空白修复

日期：2026-11-05；本地版本：0.1.13 / versionCode 14。

## 问题与根因

用户截图中的类别图标被裁切、两行间隔异常，源于类别分页器放在纵向 ScrollView 内，同时用内容高度计算每行高度。内容和容器相互撑大，第二行被挤到计算器下方；父容器的 flexGrow 又保留了整块空白。输入备注时额外的“完成备注”行继续占用 48dp 及间隔。

## 修改

- 去掉类别外层纵向 ScrollView，页面采用固定视口。父容器测量实际高度，预留金额键盘四行和备注区域后，确定两行类别的上限高度。
- 类别最多四列两行，超出仅横向翻页。分页器不再根据自身内容反推高度；无分页时删除整条页码栏，类别不足一行时不预留空第二行。
- 类别和计算器直接相邻；大屏剩余高度用于金额按键，小屏将收支切换合入顶栏。固定页不通过纵向滚动展示第二行。
- 删除“完成备注”的按钮、图标、样式及整行容器。备注编辑时隐藏类别区与金额键盘，保留常用备注；通过系统键盘完成/收起或点击现有金额区域回到金额键盘。
- 固定面板文字的缩放上限为 1.3，备注正在编辑时仍跟随系统字体；超长备注只在输入框内滚动。

## 项目留白检查

检查了页面框架、通用表单、类别管理、预算、存款计划、抽屉、账本选择与日期面板的高度、flex、空分支和底部间距。

实际清理：

1. 页面没有日期/工作区筛选时，不再渲染带间距的空包装层。
2. 共享表单没有摘要内容时，不再渲染摘要内边距；提示函数返回空值时，不生成空文字节点及组内间距。
3. 通用空状态上下间距由 32dp 调整为 24dp，普通页面底部留白由 32dp 调整为 16dp。

长列表、图标库、账本列表和长表单仍按内容正常滚动；系统安全区及必要的触控间距保留。固定视口规则适用于记一笔及复用它的明细编辑、存取款记录页。

- 两行类别完整可见，容器静置不增长，类别和计算器间隙不超过 1dp。
- 页面、类别区无纵向滚动容器；首尾所有类别和添加入口可横滑到达。
- 金额按键高度至少 48dp；无页面横向溢出。
- 输入状态无“完成备注”行；快捷备注有效；退出输入后计算器恢复原位。
- 首页返回、单类别额度保存、收入无额度、全局五主题、图标库等既有回归通过。
