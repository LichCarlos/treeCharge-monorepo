# 亮色多巴胺 UI 优化

根据用户本次要求，普通页面使用主题色画布、同色系浅色卡片、撞色功能按钮，容器和控件使用纯黑圆角描边。记一笔保持主题色计算器面板，其余部分使用撞色。此规范取代先前暖白画布、黑色主按钮的视觉约定。

## 实现

唯一主题入口为 `apps/mobile/src/theme.tsx`，扩展已有五个 palette，没有增加独立主题状态。主题选择和本地持久化键保持原样。`ui.tsx` 通过动态颜色读取与按主题缓存的共享样式统一页面、按钮、输入框、卡片和弹窗。

| 主题 | 主题色 | 功能撞色 |
| --- | --- | --- |
| 暖黄 | #FFDB07 | 紫 #B6A1FF |
| 森林绿 | #1BE349 | 粉 #FF99CB |
| 海蓝 | #73BBFF | 橙 #FFAC6B |
| 珊瑚 | #FF8868 | 青 #80D9F7 |
| 紫藤 | #C79DFC | 青柠 #C9F261 |

类别管理原来的模块级静态样式改为按主题缓存，避免切换后仍显示旧背景。日期面板、账本选择器、类别筛选、底栏和侧边抽屉均沿用全局配色。类别与计划进度轨道保留浅底，黑色填充不再和轨道融为一体。

描边统一 #000000：卡片、按钮、输入框与面板通常 2dp，进度轨道 1dp。控件圆角 12dp、卡片 16dp、弹窗 24dp。删除维持危险色语义与白色按钮文字，收入维持深绿色文字。

## 验证

- TypeScript 类型检查与 Web 正式导出通过。
- 44 项现有逻辑测试通过。
- 对照修改前快照：470 个事件／值属性、223 个状态／API／存储调用以及可见文案保持原样。
- 五种主题逐一实时切换，检查 14 个页面／状态，并检查刷新后的持久化；隔离模拟请求未产生业务写入。
- Web 渲染检查覆盖 320、390、480、1440px；记一笔另覆盖 320×568、360×640、390×844、412×915、480×1040，保持四列三排、横向分页和无页面纵向滚动。
- 明细四个标签、日历位置、日期筛选、搜索、200 条以上流水、额度保存与返回逻辑通过回归。
- 分步表单的逐项输入、总览、草稿恢复和失败重试通过。
- 空列表和服务读取错误状态可见且无横向溢出。
- Android 原生 QA 构建成功；320×568dp、默认字号，以及 360×640dp、130% 系统字号通过抽屉、明细、额度、分步表单、系统键盘和记一笔检查。备注输入保持可见，未出现页面纵向滚动或图标与输入框重叠；应用运行日志无异常。
- 126 组文字／背景组合通过对比度检查，最低 4.63:1；包括主色、卡片、输入框、撞色、浅撞色上的正文、辅助文字、链接、收入与危险提示。
- Impeccable 静态检查无发现；结合实际截图人工检查，并非仅凭静态扫描判断视觉效果。
