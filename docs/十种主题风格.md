# 简约／撞色主题

“我的 → 主题风格”提供两组共十种设计：

| 风格 | 可选颜色 | 页面与操作 |
| --- | --- | --- |
| 简约 | 暖黄、森林绿、海蓝、珊瑚、紫藤 | 暖白背景、白色卡片、浅分隔线、同色系深色主按钮；入口和选中态使用主题浅色 |
| 撞色 | 暖黄、森林绿、海蓝、珊瑚、紫藤 | 明亮主题色背景、同色系卡片、互补撞色按钮、纯黑圆角描边 |

## 全局状态与兼容

仍由 `src/theme.tsx` 和同一个 ThemeProvider 管理，沿用 `ui-theme:v1` 持久化键。现有 yellow／green／blue／coral／violet ID 继续表示撞色，新增 simple-yellow 等五个 ID 表示简约，升级不会重置已选的撞色主题。默认保持撞色暖黄。

背景、卡片、输入框、操作按钮、按钮文字、分隔线、描边宽度、计算器按键和汇总金额均采用语义令牌，页面无需另写一套业务组件。ThemePicker 仅负责主题选择；账本、流水、类别、预算和计划继续共用原组件及数据状态。
