# 记账备注键盘收起留白修复

更新日期：2026-11-04。移动端 0.1.9 / versionCode 10。

## 问题与处理

在 Android 记录页面输入备注后，计算器恢复时底部出现额外空白。旧版隔离测试包在 Android 15 小屏模拟器复现：完成按钮的底部坐标从 1220 变为 1172，整体上移 48 像素。

记录页使用 `KeyboardAvoidingView` 的 `height` 补偿。Android 收起键盘时的最终坐标可能保留导航栏高度，导致组件继续扣减可用高度。透明系统栏下原生窗口本身未完全避让键盘，不能直接移除全部高度补偿。

Android 仅在实际键盘显示期间启用 `height` 补偿，收起后恢复完整 flex 布局，避免继续使用关闭事件中残留的偏移。iOS 保留原有键盘避让。新增和编辑记录共用同一个 `RecordComposer`，修复同时生效。

备注输入时隐藏计算器并保留备注输入框、金额及常用备注；键盘收起后恢复计算器，保留备注和金额。不增加固定高度或底部填充来抵消问题。

## 验证

- 移动端类型检查和 42 项业务自动检查通过。
- Android 15 / API 35、720×1280 小屏模拟器使用独立测试包与模拟接口验证，没有连接生产账号。
- 新增、编辑记录分别重复输入备注，通过“完成备注”、点击金额、系统返回键收起键盘。八次恢复后完成按钮底部均为 1220，输入前后偏差为 0，计算器底部为 1232，没有新增空白。
- 验证键盘显示时备注位于键盘上方、常用备注一键填入、键盘隐藏后计算器恢复，以及备注随金额保存成功。没有 ReactNativeJS 或 AndroidRuntime 错误。
- 正式 APK 使用原有签名，包名 `com.charge.personal`，内嵌正式 HTTPS API，不含隔离测试入口或私密配置。
