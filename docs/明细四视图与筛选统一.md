# 明细四视图与筛选统一

本地版本 0.1.15 / versionCode 16。

## 页面与日期

收支明细下统一显示四个同级标签：收支流水、类别额度、收入明细、月度预算。移除原月度预算子路由，四个视图的返回上一级均为账本管理。

四个视图共用顶部标签、账本和日期栏。SectionList 与 ScrollView 使用相同顶部内边距、相同 8dp 内容间距，移除类别额度原先隐藏输入框的占位。

- 收支流水保留所选周期内的收支记录。
- 收入明细新增相同日期选择入口，按所选周期展示收入，不再默认全部日期。
- 类别额度、月度预算按月管理，共用日期栏的月份选择模式；切入时保留当前日期锚点并切为月份。
- 点击类别查看全部历史明细的现有行为保留，超过 200 条记录仍可完整查询。

## 筛选与搜索

流水和收入共用 `TransactionFilters`，左侧为类别下拉入口，右侧为搜索输入。下拉面板只显示当前账本真实类别；收入视图只列支持收入的类别。同名类别以 ID 独立筛选。

搜索支持备注、类别、账本、日期、按元展示的金额，支持大小写归一、空白分隔组合词，以及 `￥1,234.56元` 等金额输入。筛选结果按日期升序；对应汇总与筛选后的结果一致。

切换视图清空类别筛选和搜索；切换账本清空类别筛选。已删除类别不再作为有效筛选条件。

类别额度、月度预算不渲染输入框、类别下拉或空占位，日期栏下直接展示相关内容。

## 复用与验证

- 日期继续复用 `PeriodPicker`，新增 `monthOnly` 模式。
- 额度卡片继续复用 `CategoryDetailsList` / `CategoryAllowanceBar`。
- 单条额度编辑继续复用 `BudgetEditor`，只提交选中类别，工资及其他类别保持原值。
- 使用主题和空间 tokens，不引入新的主题或图标体系。

验证使用独立模拟数据，不修改服务器账目。Web 覆盖 320×568、390×844、480×1040；比较四个标签及日期栏的实际坐标，检查占位移除、类别筛选、备注/金额查询、日期切换、单条预算保存、历史第 205 条记录和返回路径。相关测试见 `tests/transaction-filter.test.mjs`；验证日志在 `.work/details-tabs-*`。

移动端 TypeScript、41 项现有及新增单元测试、三种 Web 视口通过。布局扫描无命中。Android API 35 独立测试应用检查 360×640、320×568dp 和 130% 字号，复核相同标签/日期坐标、输入控件、按日期展示收入及返回路径；常规尺寸另验证类别下拉、金额搜索、单类别编辑及月份面板。模拟器验证不替代所有品牌真机输入法测试。
